# Frontera de integración futura de L.U.M.I.A.

Esta carpeta NO contiene el VRM ni el proyecto L.U.M.I.A. MOTION.

En AP-02 solo se utiliza un placeholder geométrico con nombre AP02_Test_Agent_NOT_LUMIA. En una etapa futura, un adaptador cargará el VRM aprobado mediante una referencia externa, sin modificar materiales, rig, expresiones ni animaciones del proyecto original.
