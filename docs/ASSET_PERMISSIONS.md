# Protocolo de activos y permisos

El enlace Matterport público sirve solo como referencia visual hasta que se acredite autorización para descargar, exportar o reutilizar los contenidos.

- Código matterport-dl: Unlicense (vendor preservado, sin ejecución).
- Contenido Matterport: derechos independientes del código; no se archiva ni redistribuye basándose solo en la visibilidad pública del tour.
- Vía preferida: solicitar al titular exportación oficial MatterPak/OBJ u otros archivos apropiados, con permiso explícito de edición y uso en el entorno privado.
- Vía alternativa: modelar habitaciones a partir de medidas y referencias de utilización autorizada; registrar autoría, fecha, alcance y límites de licencia.
- No introducir cookies, tokens, URLs firmadas, direcciones personales, imágenes privadas o activos sin autorización en este repositorio público.
- Si algún material es licenciado solo para uso local, conservarlo fuera de Git con un manifiesto privado.
